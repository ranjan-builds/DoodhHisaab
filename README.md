# DoodhHisaab

DoodhHisaab is a lightweight web app for tracking dairy-related calculations, records, and daily summaries. It is built using plain HTML and JavaScript, making it easy to run without any build setup.

## Features

- Simple and fast user interface
- Daily dairy / milk accounting tracking
- Easy-to-edit JavaScript-based logic
- Works directly in the browser
- No dependencies or framework setup required

## Project Structure

- `index.html` – main application page
- `style.css` – styling for the UI
- `script.js` – application logic and interactions
- `README.md` – project documentation

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ranjan-builds/DoodhHisaab.git
   ```
2. Open the project folder.
3. Launch the app in a browser:
   - Open `index.html` directly, or
   - Serve the folder locally with a simple web server, for example:
     ```bash
     cd DoodhHisaab
     python -m http.server 8000
     ```
4. Visit `http://localhost:8000` in your browser.

## Notes

This project is intentionally simple and uses static web technologies, which makes it easy to customize and extend.
